## P1 — 核心业务功能（AI 对话 + 数据填充 + 饮食记录 + 记账）

### P1-1 AI 对话系统（核心卖点，最难）

- [x] FR-25 多轮对话：上下文记忆最近 20 条消息，存储到 conversations 表
- [x] FR-26 长期记忆：定期从对话提取用户事实 → long_memories 表，后续对话中引用
- [x] FR-27 SSE 流式输出：用户可看到 AI 逐字生成，EventSource 或 fetch + ReadableStream
- [x] FR-28 Tool Calling（10 个工具）：
  - [x] `search_foods` — 搜索食物库（关键词+分类）
  - [x] `get_food_nutrition` — 查某食物的营养数据
  - [x] `get_user_preferences` — 查用户饮食偏好分析结果
  - [x] `get_expense_summary` — 查用户账单统计
  - [x] `get_diet_records` — 查用户近期饮食记录
  - [x] `suggest_recipe` — 根据偏好和营养数据推荐食谱
  - [x] `recommend_food` — 综合推荐食物（决策辅助）
  - [x] `add_diet_record` — AI 代记饮食
  - [x] `analyze_food_image` — 图片识别（Qwen VL）
  - [x] `get_nearby_food` — 附近推荐（占位）
- [x] FR-29 所有 AI 建议必须有数据/工具依据 → System Prompt 约束
- [ ] FR-30 对话页快捷触发食物决策（「帮我选个晚饭」等意图识别）
- [x] RAG 集成：chromadb 向量检索 + 中文关键词回退
- [x] 提示词工程：System Prompt 分层（基础人设层 + 工具调用层 + 安全约束层）
- [x] 多模态：支持在对话中分析用户上传的食物图片（Qwen VL）
