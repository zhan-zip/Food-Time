## P2 — 特色功能（差异化竞争力）

### P2-1 DIY 拖拽烹饪（方案 C：双开门冰箱 + 岛台）

**已确定设计方案**（2026-07-24 讨论选定）：

| 设计点 | 说明 |
|--------|------|
| 冰箱初始状态 | 默认关闭，提示用户点击打开，CSS transition 模拟开门动画（左右门分开） |
| 食材分区 | 双开门左(🥩肉类+🦐海鲜)、右(🥬蔬菜+🧈豆制品+🥚蛋奶)，每个分区内可滚动 |
| 食材卡 | emoji + 中文名 + 分类色条；无匹配 emoji 的食材使用纯文字卡片 |
| 调料台 | 底部独立横滚抽屉，始终可见 |
| 备菜盘 | 岛台中央大圆盘，点击食材→卡片飞入圆盘，可点击移除 |
| 烹饪流程 | ①选料→②[获取AI建议]→匹配已有菜谱优先→若无则AI科学建议→③选择烹饪方式(炒锅/空气炸锅/蒸锅)→④对应锅中动画→⑤保存+上传 |
| 动画 | 冰箱开门、食材飞入圆盘、火焰粒子+蒸汽升腾（仅烹饪阶段） |
| 用户引导 | 每个交互节点有文字提示（如"点击冰箱打开"、"将食材放到岛台备菜盘中"） |

**实现任务**：

- [ ] FR-10 食材列表：从数据库 foods 表按分类拉取，自动匹配 emoji → 食材卡渲染
- [ ] FR-10 双开门冰箱：关闭态→点击→CSS开门动画→显示左右分区(肉类/海鲜 | 蔬菜/豆制品/蛋奶)
- [ ] FR-10 岛台备菜盘：点击食材卡 → CSS飞入动画 → 圆盘内排列
- [ ] FR-11 调料台：底部横滚抽屉，点击添加到备菜盘
- [ ] FR-12 AI 烹饪建议：
  - 优先匹配数据库已有食谱（通过食材集合匹配）
  - 若无匹配，调用 DeepSeek 生成科学烹饪建议（步骤/火候/时间/营养）
- [ ] FR-12 烹饪方式选择 + 对应动画：炒锅(火焰+翻炒)、空气炸锅(热风+倒计时)、蒸锅(蒸汽)
- [ ] FR-13 保存为 custom_food：填写菜名+简介 → 写入 custom_recipes + foods(source='custom')
- [ ] FR-14 发布到广场：复用 public_food 接口
- [ ] FR-15 营养数据置信度：标注精确匹配/近似匹配/推断三档
- [ ] emoji 映射表：食材名→emoji 映射（如"猪肉"→"🥩"，无匹配则用文字卡片）
- [ ] 用户引导：首次进入弹出提示"点击冰箱选择食材"→选好食材后"点击获取AI建议"等
