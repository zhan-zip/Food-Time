## 四、核心流程设计

### 4.1 AI 对话流程（核心）

&#x20;tool-calling 模式：

```
用户消息 → message_processor.augment()
         → 检查消息意图（是否需调工具）
         → 构建 messages 列表（system_prompt + 历史 + 当前消息）
         → DeepSeek API（stream=True）
         → 解析响应：
            ├─ 直接文本 → SSE 推送前端（逐 token）
            └─ tool_calls → execute_tool() → 结果追加到 messages
                          → 再次调用 DeepSeek → 基于工具结果生成回复
         → 回复写入对话历史
         → 每 6 轮触发 long_memory.extract() 提取事实
```

### 4.2 自定义食物流程

```
用户拖拽食材 → 前端收集食材列表
              → POST /api/custom/cooking-suggest
              → 后端构建 Prompt（你是厨师...锅中食材...给出建议+营养JSON）
              → DeepSeek API 流式返回 → SSE 推送前端
              → 前端渲染步骤 + 营养数据预览
              → 用户确认 → POST /api/custom/save → 写入数据库
```

### 4.3 食物决策流程

```
用户进入决策页 → 选择模式：
  ├─ 筛选模式：API 查询 food 表 → 前端展示匹配列表
  ├─ 转盘模式：前端 Canvas 动画 → 随机结果
  └─ AI 推荐：POST /api/chat/stream（系统注入偏好+营养数据）
             → AI 综合推荐 3 个食物 + 理由
```

### 4.4 记账 OCR 流程

```
用户上传图片 → 前端压缩图片（限制大小）
            → POST /api/expense/ocr
            → 后端调 Qwen VL API → 返回识别结果（金额、商户、日期）
            → 前端填充表单 → 用户修正 → POST /api/expense/create
```

## 六、安全设计

1. **密码**：bcrypt 哈希存储，不明文传输
2. **认证**：JWT Token（7 天过期），前端 Axios 拦截器自动附加
3. **API Key**：.env 存储，.gitignore 排除，启动时 load\_dotenv 注入
4. **CORS**：仅允许前端域名跨域
5. **输入验证**：Pydantic Schema 校验所有请求体
6. **SQL 注入防护**：SQLAlchemy ORM 参数化查询
7. **管理员接口**：中间件校验 is\_admin 字段
